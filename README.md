# 🌐 Personal Portfolio Website

A simple personal portfolio website built using **HTML5 and CSS3** to showcase my profile, interests, projects, and contact information.

## 📌 About the Project

This project is a basic portfolio website created to practice my **HTML and CSS fundamentals**.

The website includes sections for my introduction, about me, interests, projects, social media, and a separate contact form.

## ✨ Features

* 👩‍💻 Personal introduction
* 📝 About Me section
* 💡 Interests section
* 🚀 Projects section
* 📩 Contact form
* 🔗 LinkedIn profile link
* 🎨 Custom CSS styling
* 📐 Flexbox layout for arranging sections
* 🔤 Google Fonts integration

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Google Fonts**
* **CSS Flexbox**
